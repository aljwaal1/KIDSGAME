# تحديث KIDSGAME - إضافة ألعاب ذكاء وتفكير

هذه الحزمة تضيف ألعابًا جديدة إلى تطبيق KIDSGAME داخل نفس التطبيق، مع الحفاظ على الألعاب القديمة كما هي.

## الألعاب المضافة

1. ذاكرة الصور
   - لعبة مطابقة أزواج البطاقات.
   - تقوي الذاكرة والتركيز.

2. تحدي الأنماط
   - الطفل يختار الشكل الناقص في سلسلة مرتبة.
   - تقوي التفكير المنطقي والملاحظة.

3. سودوكو الأطفال 4×4
   - نسخة مبسطة للأطفال بالأرقام 1 إلى 4.
   - تقوي المنطق وحل المشكلات.

4. المتاهة الذكية
   - تحريك البطل للوصول إلى النجمة بأقل خطوات.
   - تقوي التخطيط واتخاذ القرار.

5. الحساب السريع
   - لعبة جمع وطرح بسيطة.
   - أضفتها كهدية إضافية لأنها مفيدة جدًا للأطفال.

## طريقة التطبيق

1. فك الضغط عن هذه الحزمة.
2. انسخ محتوياتها داخل جذر مستودع KIDSGAME.
3. شغّل:

```bash
python apply_kidsgame_update_v1.py
```

4. ارفع التغييرات إلى GitHub.
5. شغّل GitHub Actions لبناء APK.
