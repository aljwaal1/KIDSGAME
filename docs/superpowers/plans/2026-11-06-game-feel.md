# Game Feel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans task-by-task.

**Goal:** Individually audit and repair physics, touch logic, clarity, and audio-event synchronization across the 27 existing games.
**Architecture:** Testable hockey simulation and contact geometry, generation-guarded animation tasks, synchronous input locking, nonblocking audio with per-channel ordering and priority.
**Tech Stack:** Existing Flutter/Dart/audioplayers; no new dependency.
**Spec:** docs/superpowers/specs/2026-11-06-game-feel-design.md

## Global Constraints
- Keep existing designs, bundled audio, game identities, and rules unless they demonstrably disagree with interaction.
- Preserve main; update only the existing review branch with a head lease.
- No claimed physical-device QA without evidence.

## Review Focus
- Narrow/tall fields: circles must touch at their rendered edges.
- Rapid taps/reset: one score per action and no stale asynchronous mutation.
- Outgoing contact: no repeated impulse or sound.
- Simultaneous sounds: victory not interrupted by minor events; mute cancels pending work.
- Navigation: no disposed-state writes, stale speech, or physics catch-up.
