# ملعب الأطفال

تطبيق Flutter عربي للأطفال يضم ألعابًا تعليمية وذهنية وتراثية، ويعمل دون اتصال بالإنترنت.

## الألعاب الحالية

### الألعاب الأساسية

- إكس أو: ضد صديق أو ضد الكمبيوتر، مع مستويات متغيرة للكمبيوتر.
- بزل الأرقام: مستوى 3×3 ومستوى 4×4 مع حفظ أفضل عدد حركات.
- فقاعات الحروف: تدريب على الأبجدية العربية والمتتاليات الصحيحة.

### الذكاء والحساب

- ذاكرة الصور.
- تحدي الأنماط.
- سودوكو الأطفال 4×4.
- المتاهة الذكية.
- الحساب السريع.

### الملاحظة والترتيب

- ابحث عن المختلف.
- ظل الشكل.
- رتّب التسلسل.

### التعليم

- تتبع وتلوين الحروف الإنجليزية الكبيرة.

### الألعاب التراثية

- الحَرّة بالحصى.
- الدحدل.
- سبع حجارة.
- السيجا.
- الخاتم.

## الواجهة والتفاعل

- واجهة عربية باتجاه RTL.
- أقسام واضحة للألعاب الأساسية والذكاء والملاحظة والتعليم والتراث.
- مؤثرات حركة واحتفال بالكونفيتي في الألعاب المدعومة.
- نظام نجوم عام يتحدث مباشرة في الصفحة الرئيسية.
- زر كتم وتشغيل الصوت في أعلى التطبيق.
- صفحة فحص داخل التطبيق لاختبار كل مؤثر صوتي وعرض آخر خطأ صوتي.
- زر مؤكد لإعادة ضبط النجوم وأفضل النتائج.

## نظام الصوت

تستخدم النسخة الحديثة حزمة `audioplayers` وتشغّل المؤثرات القصيرة بوضع منخفض التأخير. توجد مشغلات منفصلة لأصوات الواجهة، ومؤثرات اللعب، وأصوات الفوز حتى لا تقطع الأصوات بعضها.

الملفات الحالية:

- `click.wav`: أزرار الواجهة.
- `tap.wav`: لمس عناصر اللعبة.
- `move.wav`: الحركة.
- `pop.wav`: الإجابة الصحيحة أو الالتقاط.
- `wrong.wav`: الخطأ.
- `chime.wav`: إكمال مرحلة.
- `win.wav`: الفوز.

## البناء والتحقق

Workflow النسخة الحديثة:

`Build APK Direct`

يعمل عند:

- فتح أو تحديث Pull Request نحو `main` للتحليل وبناء APK تجريبي كـArtifact.
- الدمج أو الدفع إلى `main` لبناء APK الحديث وتحديث رابط التنزيل.
- التشغيل اليدوي من GitHub Actions.

مسارات APK:

- النسخة الحديثة: `apk/modern/kidsgame.apk`
- نسخة Android 4.4+: `apk/legacy/kidsgame-kitkat.apk`

## نسخة منفصلة للأجهزة القديمة

يوجد مشروع Android Java خفيف ومستقل داخل `android_kitkat_java/` للأجهزة التي تعمل بنظام Android 4.4 فأحدث.

- اسم حزمة النسخة الحديثة: `com.explapp.kidsgame`
- اسم حزمة النسخة القديمة: `com.explapp.kidsgame.legacy`
- Workflow النسخة القديمة: `Build KitKat APK Separate`
- النسخة القديمة تستخدم رسومات برمجية ونغمات `ToneGenerator` خفيفة.

### ضمان عدم التداخل

- مشروع Flutter الحديث لا يقرأ أو يبني ملفات `android_kitkat_java/`.
- مشروع KitKat لا يستخدم مكتبات Flutter.
- كل APK محفوظ في مجلد مستقل.
- يمكن تثبيت النسختين معًا دون أن تستبدل إحداهما الأخرى.
