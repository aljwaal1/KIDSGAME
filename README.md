# ملعب الأطفال

تطبيق Flutter عربي للأطفال يحتوي ثلاث ألعاب ممتعة:

- إكس أو (مع وضع ضد صديق أو ضد الكمبيوتر).
- بزل الأرقام (سهل 3×3 أو صعب 4×4).
- فقاعات الحروف (الأبجدية العربية الكاملة).

## تحديث v4 — تصميم جديد بالكامل

**الشكل والألوان**

- هوية بصرية جديدة بخطين عربيين مخصصين: Changa للعناوين المرحة، و Cairo للنصوص.
- أيقونة تطبيق جديدة برسمة نجمة كرتونية ودودة (تظهر أيضًا داخل التطبيق كشخصية مرافقة).
- بطاقات وألوان متدرجة محسّنة لكل لعبة، مع ظلال ولمسات لمعان على الفقاعات.

**حركة وتفاعل**

- احتفال بالكونفيتي (Confetti) عند الفوز في أي لعبة، بدون أي مكتبة خارجية.
- خط الفوز في إكس أو يُرسم بحركة تدريجية بدل الظهور المفاجئ.
- رموز X و O تظهر بحركة "نطّة" عند وضعها.
- بلاطات بزل الأرقام تنزلق بحركة سلسة بدل القفز المباشر.

**ألعاب أعمق**

- إكس أو: وضع "ضد الكمبيوتر" بذكاء اصطناعي بسيط (يفوز، يصد، ثم يلعب بذكاء)، ولوحة نتائج X / O / تعادل.
- بزل الأرقام: مستويين (3×3 و 4×4) مع حفظ أفضل عدد حركات لكل مستوى.
- فقاعات الحروف: الأبجدية الكاملة، وعدد الفقاعات يزداد تدريجيًا مع التقدم، وحفظ أفضل متتالية صحيحة.
- نظام نجوم عام يُجمع من الألعاب الثلاث ويظهر في الصفحة الرئيسية.
- زر كتم/تشغيل الصوت في الأعلى، وزر "إعادة ضبط التقدم" في صفحة المطور.

**أصوات جديدة**

كل الأصوات أُعيد توليفها لتكون أكثر مرحًا ونعومة للأطفال:

- pop.wav للفقاعات.
- move.wav للبزل.
- tap.wav لإكس أو.
- win.wav للفوز (لحن احتفالي صاعد).
- wrong.wav للخطأ (صوت لطيف وغير مزعج).
- chime.wav عند إكمال جولة فقاعات الحروف.
- click.wav لأزرار الواجهة العامة.

كل هذا يعمل بدون إنترنت بالكامل.

## البناء

شغل GitHub Actions باسم:

`Build APK Direct`

بعد نجاح البناء سيظهر APK مباشرة داخل:

`apk/kids-games-arena.apk`

لا يوجد Release ولا AAB. الأيقونة الجديدة تُولَّد تلقائيًا أثناء البناء عبر حزمة `flutter_launcher_icons`.


## نسخة منفصلة للأجهزة القديمة

يوجد مشروع Android Java خفيف ومستقل داخل `android_kitkat_java/` للأجهزة التي تعمل بنظام Android 4.4 فأحدث. لا يتم دمجه مع مشروع Flutter الحديث.

- APK الحديث: `apk/kidsgame.apk`
- APK القديم: `apk/kidsgame-kitkat.apk`
- Workflow القديم: `Build KitKat APK Separate`

النسخة القديمة تستخدم رسومات برمجية وأصوات Tone خفيفة لتقليل استهلاك الذاكرة والعمل دون إنترنت.
