# ملعب الأطفال

تطبيق Flutter عربي خفيف للأطفال يحتوي ثلاث ألعاب:

- إكس أو.
- بزل الأرقام بتحريك المربع الفارغ.
- فقاعات الحروف.

## تحديث v3

- فقاعات الحروف تعرض الحرف المطلوب بحجم كبير.
- الفقاعات أصبحت 3 أو 4 وتتحرك يمينًا ويسارًا ببطء.
- أصوات خاصة قصيرة داخل التطبيق:
  - pop.wav للفقاعات.
  - move.wav للبزل.
  - tap.wav لإكس أو.
  - win.wav للفوز.
  - wrong.wav للخطأ.
- إكس أو يعرض خطًا فوق الرموز الثلاثة عند الفوز.
- بزل الأرقام يعطي صوتًا عند تحريك المربعات وصوتًا عند الفوز.

## البناء

شغل GitHub Actions باسم:

`Build APK Direct`

بعد نجاح البناء سيظهر APK مباشرة داخل:

`apk/kids-games-arena.apk`

لا يوجد Release ولا AAB.
